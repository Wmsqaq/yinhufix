  银狐病毒综合修复工具  YinHuFix v1.10.20261031 @NovaPupil_
  更新日期：2026-10-31
================================================================

这个工具用来处理电脑中了银狐（SilverFox）木马之后留下的
各种残局。中招后的典型表现：

  运行任务管理器、注册表、杀毒软件或安装程序时弹出
  "你的组织使用适用于企业的应用控制阻止此应用"
  杀毒软件打不开，或者被禁用了
  Windows 更新被关掉了
  有隐藏进程、可疑的启动项或服务

================================================================
【怎么用】

推荐直接双击 YinHuFix_GUI.exe（自动提权）。
没有 exe 就双击 YinHuFix_GUI.bat，效果一样。
也可以用命令行版：右键 YinHuFix_综合修复.bat，
以管理员身份运行，按数字选功能，两个版本功能一致。

图形界面左侧为十个功能按钮，单击查看功能说明，
双击同一按钮运行。任务运行时右侧显示实时结果摘要
（发现/处置/失败计数与关键输出），下方滚动完整日志。
高风险操作均会先弹出确认框，确认后执行，
过程中无需再手动操作。

[1] 修复 WDAC 应用控制拦截
    清掉可疑的 .cip 策略文件和遗留的 p7b 单策略，
    恢复被改的系统限制项，顺带检查智能应用控制状态。
    有改动会提示重启（工具不会替你重启），没改动就不用。

[2] 解除杀毒软件限制（高风险，执行前会再次确认）
    只处理高置信度的可疑项：已知 IOC 命名、Public 目录中
    的未签名载荷等。ASUS、ROG、Armoury、Intel、NVIDIA
    等厂商签名的计划任务和服务一律不做批量禁用。
    IFEO 仅清理本工具写入的标记，不改动用户与软件的
    Debugger 配置。隐藏进程会先列出，确认后才劫持并终止。
    系统恢复后可再运行本功能，工具会清除自身写入的
    IFEO 标记。完成后建议重启并使用杀毒软件全盘扫描。

[3] 隐藏进程与启动项扫描（仅报告，不处置）
    六项扫描：隐藏进程、Run/RunOnce 启动项、解释器类
    启动项、可疑计划任务、Public 目录释放物，以及
    Defender 防护状态和已知 C2 回连检测。发现问题后
    使用功能 2 或 7 处置。

[4] 恢复 Windows 更新
    用 sc qc 判断服务状态，能识别被恶意工具改到几年后
    的"暂停更新"，确认后清掉（如果是自己主动暂停的，
    选 N 保留）。清策略只删真正阻断更新的那几个值，
    版本锁定这类正常配置会保留。

[5] 清除系统限制注册表项
    恢复被禁用的任务管理器、注册表编辑器、命令提示符、
    运行对话框、Defender 等功能，并检测 UAC 状态
    （EnableLUA=0 时会提示）。

[6] 获取杀毒软件安装包
    列出常用杀毒软件，本地已有安装包则直接使用，否则自动
    下载（下载地址可在"杀毒软件安装包配置"中自定义，
    云端策略也会下发新条目）。360 急救箱下载解压失败时
    会自动重试。

[7] 木马变体专项清除
    针对 2026 年 9 月分析出的门控投递器族变体：伪装
    Defender 更新包（install.g*.exe）、向 Public 目录
    释放载荷、静默停止 WinDefend、回连阿里云 OSS 的 C2。
    命中的 IOC 会列出，确认后一键处置。

[8] 检查更新
    Gitee 和 GitHub 双路线，Gitee 连不上自动换 GitHub。
    下载前校验 SHA-256，防止包被换。更新在程序退出后
    由安装器自动完成（含主程序自身）。更新的是程序文件，
    setup 目录里的杀软安装包不走这条路。仓库：
    novapupil/yinhufix（Gitee）和 Wmsqaq/yinhufix（GitHub）。
    令牌不写进脚本，匿名优先，私有仓库场景运行时才读
    本机凭据。

[9] 重置 hosts 配置
    银狐及部分流氓软件会篡改 hosts（屏蔽杀软官网、指向
    恶意站点）。本功能先统计并预览自定义映射，确认后
    备份至 hosts_backup 目录（文件名含日期时间），再恢复
    系统默认 hosts 并刷新 DNS 缓存。如需还原，将备份
    文件内容复制回即可。

[T] 微步云沙箱在线检测
    在默认浏览器中打开微步在线分析页 s.threatbook.com。
    本地杀毒软件无告警而文件可疑时，可将文件哈希粘贴至
    页面查询第三方判定，也可上传样本进行动态分析。
    注意：上传样本即提交至第三方云端，涉隐私文件请勿上传。
    页面无法打开通常为 hosts 被篡改或网络中断，
    请先使用功能 9 重置后再试。

[Q] 退出

命令行版的窗口标题会随功能切换，界面彩色显示。

================================================================
【修复后还是被拦截？】

Win11 的智能应用控制（Smart App Control）是另一套机制，
这个工具不管它。要关的话：
设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器
控制 → 智能应用控制设置 → 关闭。
注意：关了就再也开不回来了。

================================================================
【杀软误报说明】

功能 2 和 7 要禁任务、劫持进程、删文件，动作和病毒太像，
360、火绒、Defender 报 HEUR 属于正常现象。被拦的话加个
白名单，或者临时关掉实时防护再跑。

================================================================
【新变种背景】

2026 年 9 月的样本分析确认了一类新变种：伪装成 Defender
更新包（install.g*.exe、AM_Delta_Patch*.exe），只在真实
Defender 引擎在位且网络可达的机器上激活，沙箱里装死。
落地后往 C:\Users\Public 的随机目录放四个文件：腾讯签名
的白加黑宿主 EXE、加壳 DLL、PNG 隐写容器、加密配置；
注册根路径隐藏的计划任务（如 c54u2）登录触发、每分钟
重拉；静默停掉 WinDefend/WdNisSvc；回连
msi8s0.oss-cn-beijing.aliyuncs.com（61.135.144.223:443）。
整个过程 Defender 实时防护零检出。

2026 年 10 月底又抓到多批次同类：有的整个伪装成 OneDrive
更新器（agent_10292014.exe），开机自启、计划任务、WMI 事件
订阅、Run 键四路持久化，装根证书，还会删掉旧版残留完成
换代；有的把服务释放到 C:\ProgramData\host 回连 7788 端口；
还有 VMP 加壳的窃密器，专偷浏览器数据、加密货币钱包和
Telegram。功能 7 已把这些批次全部纳入扫描与处置范围。

防这类东西就一条：别运行来路不明的"系统更新""补丁"
EXE，微软的更新只走系统自带的 Windows Update 通道。
命中过任一 IOC 的机器，按已感染处理：断网、查杀、
必要时重装。

================================================================
【系统要求】

Windows 10 1903 及以上，或 Windows 11，需要管理员权限。
纯批处理，不用装 Python 和任何运行库。
