【解决什么问题】
  被银狐(SilverFox)木马侵入后可能出现：
    · 运行任务管理器/注册表/杀软/安装程序时提示 "你的组织使用适用于企业的应用控制阻止此应用"
    · 杀毒软件打不开/被禁用
    · Windows 更新被禁用
    · 存在隐藏进程、可疑启动项、可疑服务

================================================================
【主程序用法】
  右键 YinHuFix_综合修复.bat → 以管理员身份运行（自动弹 UAC 提权）。
  出现数字菜单后按数字选择功能：

  [1] 修复 WDAC 应用控制拦截
      清理可疑 .cip 策略与遗留 p7b 单策略文件，
      并检测智能应用控制(SAC)状态与系统限制注册表项。
      有改动时提示重启，无改动则无需重启。

  [2] 解禁杀毒软件（影响较大，进入需二次确认）
      v1.5 智能化误杀防护（重点）：
      · 计划任务：只把"高置信可疑"项加入待禁用列表
        （已知IOC名 / Public 载荷 / 用户可写目录中的未签名
        载荷）；有效签名的厂商任务（ASUS/ROG/Armoury、
        Intel、NVIDIA 等）自动保护，绝不批量禁用其余任务
      · 服务：只处理"用户可写路径(Public/AppData/Temp)中
        的脚本解释器或已知IOC"，厂商签名服务一律保护
      · IFEO 清理改为只删本工具标记（NovaPupil），不再
        清空第三方软件和用户自设的 Debugger 配置
      · 隐藏进程：列出后确认才劫持（IFEO Debugger 标记为
        NovaPupil，与病毒自身劫持区分）并终止
      系统干净后重跑一次本功能，第 0 步会自动清除本工具
      写入的 IFEO 项。完成后必须重启，并安装 360/火绒 全盘扫描。

  [3] 查找隐藏的进程和启动项
      v1.2 修复了启动项扫描失效的问题，并新增
      RunOnce 键与解释器类启动项报告。
      v1.4 扩展为 6 项深度扫描: 新增可疑计划任务
      (根路径隐藏/Public 载荷/已知IOC名)、Public 目录
      释放物、Defender 防护状态与已知 C2 回连检测。

  [4] 恢复 Windows 更新
      v1.5 重写（修复失效问题）：
      · 服务检测改用 sc qc 判定（原 reg 查询方式在部分
        机器上返回空导致误报"正常"）
      · 新增"暂停更新"检测：恶意工具常把暂停到期时间改到
        数年后锁死更新，确认后可清除（主动暂停的请选 N）
      · 策略清理改为精确按值：只删 NoAutoUpdate=1、
        AUOptions=1、DisableWindowsUpdateAccess 等阻断值，
        版本锁定(如 24H2)、AUOptions=3 等合法配置一律保留

  [5] 清除系统限制注册表项
      v1.2 新增检测 UAC 被禁用(EnableLUA=0)。

  [6] 获取杀毒软件安装包
      v1.2 下载优先使用系统 curl（有进度显示），失败自动
      回退 PowerShell；修复带 ? 参数链接的文件名问题。

  [7] 新变种专项清理（v1.4 新增，调用独立功能模块）
      基于 2026-09-13 深度分析报告的门控式投递器族专项：
      扫描并处置 已知IOC计划任务 / Public 目录释放物 /
      投递器本体(伪装 Defender 更新包) / Defender 致盲 /
      已知 C2 回连。处置需二次确认，全程可审计。

  [8] 检查更新（v1.6 新增，调用独立功能模块）
      Gitee / GitHub 双路线自动选择：优先 Gitee（国内
      直达，4 秒超时自动切换），GitHub 兜底；下载更新包
      前 SHA-256 完整性校验，防篡改；更新文件在程序退出
      后由安装器自动替换（含主程序自身）。
      更新内容为程序文件（bat/说明/配置），不含 setup
      目录内的杀毒软件安装包。仓库: novapupil/yinhufix
      (Gitee) 与 Wmsqaq/yinhufix (GitHub)。
      令牌安全: 令牌不写入脚本，匿名优先，私有仓库场景
      运行时才读本机凭据。

  [9] 一键清空 hosts 配置（v1.6 新增，调用独立功能模块）
      银狐/推广软件常通过 hosts 劫持域名（屏蔽杀软官网、
      指向恶意站点）。本功能: 统计并预览自定义映射 →
      确认后自动备份到 hosts_backup\ 目录（带日期时间
      文件名）→ 恢复为系统默认 hosts → 刷新 DNS 缓存。
      备份文件可随时用记事本复制回原处恢复。

  [Q] 退出

  窗口标题会随功能切换，界面彩色显示。

【修复后还是被拦截？】
  · Win11 智能应用控制(Smart App Control)
    设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制
    → 智能应用控制设置 → 关闭（注意：关闭后不可再开启）

【杀软误报说明】
  本工具功能 2/7 的行为（禁用计划任务/劫持隐藏进程/删除系统文件/
  WMI 结束进程/删除释放物）与恶意软件特征重叠，
  360/火绒/Defender 可能报 HEUR 误报，
  属正常现象。若被拦截请加白名单或临时关闭实时防护后运行。

【v1.4 新变种背景（门控式投递器族）】
  2026-09-13 深度分析报告确认一类新变种：
    · 伪装成 Defender 更新包（install.g*.exe / AM_Delta_Patch*.exe）
    · 仅在真实 Defender 引擎在位且网络可达时激活（沙箱中装死）
    · 释放四件套至 C:\Users\Public\XmdaDM\（随机目录名）:
      白加黑宿主 EXE(腾讯签名) + 加壳 DLL + PNG 隐写容器 + 加密配置
    · 注册根路径隐藏计划任务（如 c54u2）, 登录触发+每分钟重拉
    · 静默停止 WinDefend/WdNisSvc（无篡改事件记录）
    · 回连 msi8s0.oss-cn-beijing.aliyuncs.com (61.135.144.223:443)
  该族样本对 Defender 实时防护全程零检出。排查要点:
    · 功能 7 扫描以上全部 IOC 并可一键处置
    · 不要运行来源不明的"系统更新/补丁"类 EXE
    · 微软更新只走系统内置 Windows Update 通道
    · 命中任一 IOC 即按已感染处置（断网 → 查杀 → 必要时重装）
